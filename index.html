Export your UniFi network topology as zoomable SVG, PDF, or an editable draw.io diagram, with real Ubiquiti device artwork.

📌 About This Tool

Managing network hardware requires a clear view of how devices connect. UniFi networks often hide these connections within complex menus. This software extracts your network data and converts it into a visual map. You get a clear diagram that shows your switches, access points, and gateways in one view.

The tool uses official Ubiquiti hardware icons to ensure your diagram looks professional and matches your actual equipment. Whether you need to document your home setup or a business installation, this application creates a file you can edit or share.

⚙️ System Requirements

  • Windows 10 or Windows 11
  • At least 4GB of RAM
  • A basic understanding of your UniFi controller login
  • Internet connection to download the tool

📥 Download and Setup

Follow these steps to prepare your system:

  1. Visit the project release page to download the software.
  2. Locate the downloaded file in your Windows Downloads folder.
  3. Double-click the file to launch the installation process.
  4. Follow the prompts on your screen to finish the setup.
  5. Find the unifi-map shortcut on your desktop or start menu to open the program.

🎨 Using the Software

Once you open the application, it will ask for your UniFi network credentials. The software uses these to gather information about your connected devices. It does not store your password on any external server.

After the tool connects to your controller, it will generate a list of devices. You can choose to export this map in several formats:

  • SVG: A high-quality file that you can zoom in on without losing clarity.
  • PDF: A document format perfect for printing or attaching to reports.
  • Draw.io: An editable diagram file that lets you move icons and add custom labels.

Select your preferred format, choose a save location, and click the export button. The process takes a few seconds, depending on the size of your network.

💡 Troubleshooting

If the program fails to connect, check your UniFi controller address. Ensure the port number is correct. If your firewall settings prevent the connection, check your Windows Security settings to allow the application access to your local network. Most issues involve incorrect controller login details or a blocked network port.
